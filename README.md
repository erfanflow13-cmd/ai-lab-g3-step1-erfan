# پروژه دوز (Tic-Tac-Toe)

گروه: [1]
نام: [عرفان دهستانی]
گام ۱: تعریف مسئله

## ایده پروژه
یک ربات می‌سازیم که دوز بازی کند و با بازیکن تصادفی مقایسه‌اش می‌کنیم.

## PEAS
- **هدف:** بردن (اگر نشد، مساوی شدن)
- **محیط:** صفحه ۳×۳ و یک حریف
- **کار ربات:** گذاشتن X یا O در یک خانه خالی
- **چیزی که ربات می‌بیند:** وضعیت صفحه

## ویژگی‌های محیط
1. **قابل مشاهده:** کامل، چون کل صفحه دیده می‌شود
2. **تعداد بازیکن:** دو نفر و رقابتی
3. **قطعی:** بله، شانسی در کار نیست
4. **ترتیبی:** بله، هر حرکت روی حرکت‌های بعدی اثر دارد
5. **ایستا:** بله، صفحه خودش تغییر نمی‌کند
6. **گسسته:** بله، فقط ۹ خانه داریم

## معیار ارزیابی
ربات را ۱۰۰ بار با بازیکن تصادفی بازی می‌دهیم و می‌شماریم چند بار برد، مساوی یا باخت. نصف بازی‌ها را با X و نصف را با O بازی می‌کند.
